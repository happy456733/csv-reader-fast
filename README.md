A fast, dependency-free drop-in replacement for csv-reader 1.0.0: reads broken CSV files (stray CRs, unterminated quotes, quote junk, short/long rows) and returns byte-identical answers, faster.

## Run it

```sh
node main.ts
```

`main.ts` reads every case from `/input/cases.json`, answers each with `run` from `solve.js`, and writes `/output/answers.json`.
